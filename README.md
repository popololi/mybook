# 📖 我的小说阅读器（基于 legado-e 二次开发）
> 本项目基于开源项目 legado-e 二次开发，源自原项目 Legado(gedoor/legado)，遵循 GPL-3.0 开源协议。

## ✨ 功能特性
- 阅读界面高度自定义：字体、字号、行距、段间距、页边距、背景色、多种翻页动画
- 完整书架管理，支持本地导入 TXT / EPUB 电子书
- 书签、阅读笔记、TTS文本朗读
- 多套阅读主题，支持日间/夜间深色模式

## 📱 支持平台
- Android 客户端
> Windows端：可使用安卓模拟器运行本安卓APK（后续可单独开发独立Windows客户端）

## 📥 安装使用
1. 在仓库 Actions 或 Releases 下载编译好的 APK
2. 安卓手机安装，允许安装未知来源应用
3. 导入本地小说，即可开始阅读
